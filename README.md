# Vivek Kumar Sen — Portfolio Website

A responsive, dark-premium personal portfolio built with plain HTML, CSS and JavaScript. No build step or framework required.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Edit the content in `index.html` and styling in `styles.css`.

## Personalise before publishing
Search `index.html` for:
- `https://github.com/` — replace with your actual GitHub profile and project repository URLs.
- `https://www.linkedin.com/` — replace with your actual LinkedIn profile URL.
- Project links — replace placeholders with live demos or repositories.
- Certification entries — confirm exact credential titles and whether each is completed, in progress, or planned.
- `profile.png` — your supplied profile photo is already included.
- `Vivek_Kumar_Sen.pdf` — your supplied resume is linked from the website.

The portfolio uses the profile details currently available: B.Tech CSE at Technocrats Institute of Technology, Bhopal; expected graduation 2027; CGPA 8.48; 1,600+ coding problems; Java, web development, DSA, Firebase and community leadership.

## Publish free with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io` (or any repository name).
2. Upload `index.html`, `styles.css`, `script.js`, `profile.png`, `Vivek_Kumar_Sen.pdf`, and this README to the repository root.
3. For a `yourusername.github.io` repository, the site will be available at `https://yourusername.github.io/`.
4. For another repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to deploy and open the URL shown under Settings → Pages.

## Notes
- This is a static front-end portfolio. The email contact link opens the visitor's email app; there is no server-side contact form.
- Google Fonts and Lucide icons load from external CDNs. The rest of the site is local.
- Add a PDF resume to the project and link it from the hero if you want a downloadable resume button.


## Certificates included
The `certificates/` folder contains the four supplied certificate PDFs. Each item in the Certifications section opens its corresponding PDF in a new tab. Keep the folder structure intact when uploading to GitHub Pages.
